Système Décisionnel : Projet SportOne

Ce projet a consisté à centraliser les données de vente (2017-2022) de SportOne, dispersées entre plusieurs formats (Excel, CSV, Access), afin de créer un entrepôt de données fiable pour le pilotage stratégique.

Chaîne de traitement ETL

  • Extraction : Récupération des fichiers sources hétérogènes.
  • Transformation (Talend) : Nettoyage des données et création des flux pour alimenter les tables de dimensions (Client, Produit) et la table de faits.
  • Stockage : Utilisation d'Oracle SQL Developer pour structurer l'entrepôt.

Analyse et Visualisation

  • Dimension Temps : Développement d'un script Python pour générer une dimension temporelle complète manquante dans les sources.
  • Dashboard (Power BI) : Conception de tableaux de bord analysant l'évolution des ventes, la performance produit et la segmentation client.

Conclusion

Ce projet a permis de livrer un système décisionnel opérationnel, surmontant des difficultés techniques liées à la qualité des données initiales. L'entreprise dispose désormais d'un outil fiable pour suivre ses résultats et orienter ses décisions stratégiques.
